### ✨ **Visual Experience & "Magic" Interactions**
The **Zia Properties** homepage is built with a focus on "Cinematic Vibe Coding." It features a high-definition aerial view of Kenyan property (`beauty.png`) enhanced with a **Ken Burns Breathing Effect**, creating a professional drone-shot feel. To guide user attention, content drifts into place sequentially: **The Title** (0.3s), **The Tagline** (0.6s), and the **"Get Started" Button** (0.9s). The navigation is a **Floating Glass Pill** that uses `backdrop-filter: blur` to frost the background in real-time. Our feature cards use **Tactile Touch Logic**—lifting 20px on interaction with an **Icon Pop** and a **Smart Accent Underline** that grows from the center.

### 🛠️ **Technical Stack & Architecture**
*   **CORE BACKEND:** [Django 5.2.5](https://www.djangoproject.com) — Powering the property management logic.

*   **UI FRAMEWORK:** [Bootstrap 5.3](https://getbootstrap.com) — For a fully responsive, mobile-first grid.
*   **VISUAL ASSETS:** [Font Awesome 6.4](https://fontawesome.com) — Interactive, high-resolution iconography.

### 🚀 **Quick Start & Local Setup Instructions**
Follow these steps to get your development environment running locally:
1.  **Prerequisites:** Ensure you have **Python 3.10+** and **Pip** installed.
2.  **Clone Repository:** 
    `git clone https://github.com`
    `cd Zia-Property-Management-System`
3.  **Virtual Environment:** 
    `python -m venv venv`
    `source venv/bin/activate` (Use `venv\Scripts\activate` on Windows).
4.  **Install Dependencies:** 
    `pip install django`
5.  **Database & Server:** 
    `python manage.py migrate`
    `python manage.py runserver`
    *Visit `http://127.0.0.1` to see the live animations!*
